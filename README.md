# N.O.V.A. 2026 Doctor Agent Foundation

> 상태: `building` — 로컬 합성 데이터와 평가 하네스 단계. 참가 신청, 코드 제출, 외부 API 호출, 제품 배포는 하지 않았다.

□ 이 기반을 만드는 이유

• N.O.V.A. 예선은 가상 환자에게 질문·진찰·검사를 고르고 최종 진단에 도달하는 Doctor Agent를 평가한다.
  - 공식 페이지에서 확인한 예선 축은 진단 정확도, 정보 획득 효율성, 임상적 안전성이다.
  - 증례당 상호작용은 최대 60턴이다. 예선은 고정 `openai/gpt-oss-20b`를 실제 증례 문맥으로 최소 한 번 호출해야 한다.
  - 예선 제출 형식은 `run.py`와 `requirements.txt`가 든 50 MB 이하 ZIP이지만, 정확한 API와 실행 계약은 참가자 가이드 공개 전이라 아직 구현하지 않는다.

• 지금 필요한 것은 신청서용 포장보다 재현 가능한 개발 토대다.
  - 이 폴더는 환자 데이터 없이 자체 작성한 합성 fixture로 대화 프로토콜, 점수 계산, 안전 규칙을 검증한다.
  - fixture 통과는 임상 성능, 실제 대회 점수, 제품 기능, 의료적 타당성을 뜻하지 않는다.

□ 현재 들어 있는 것

• `data/synthetic_cases.json`
  - 실제 환자나 외부 데이터에서 가져오지 않은 소규모 합성 대화 시나리오다.
  - 공개된 답변만 에이전트에 전달하고, 정답 진단은 평가기만 읽는다.

• `nova_doctor_agent/`
  - 고정된 질문·진찰·검사 후보에서 다음 행동을 고르는 작은 결정론 정책이다.
  - 확인 전 무제한 검사를 남발하지 않고, 후보를 가르는 최소 행동을 우선한다.
  - 이는 최종 임상 추론 엔진이 아니라 대회 인터페이스가 공개되기 전의 정책·평가 연결 검증용이다.

• `run_local_eval.py`와 `tests/`
  - 정확도, 턴 효율, fixture가 요구한 안전 행동, 금지 행동 여부를 로컬에서 반복 확인한다.
  - 표준 라이브러리만 사용한다. 새 프레임워크나 임베딩 모델은 넣지 않았다.

□ 제품으로 옮길 범위와 옮기지 않을 범위

• MediQ와 UniQdata 챗봇에 옮길 수 있는 것
  - 사용자가 빠뜨리기 쉬운 병력·증상·복약·알레르기·질문을 구조화하는 대화 순서
  - 원문, 번역문, 출처와 불확실성을 함께 남기는 진료 준비 패킷
  - 진료실 안팎의 다국어 전달과 사용자가 의사에게 물어볼 질문 정리

• 제품에 직접 넣지 않는 것
  - 최종 진단, 검사 지시, 처방 변경, 응급 여부 확정
  - 대회용 질환 분류 지식과 hidden-case 최적화 규칙
  - 동의·manifest·Core 최소 projection을 거치지 않은 건강기록 열람이나 외부 전송

• 제품 연결의 선행 게이트
  - UniQdata의 기존 DataQ 후보 검토·확정 저장·권한·철회 흐름이 실계정과 기기에서 검증돼야 한다.
  - MediQ 통역의 기계 생성 문구는 원어민·임상 검토 전 실제 의료 현장 품질 주장에 쓰지 않는다.
  - 이 대회용 코드가 제품 런타임 또는 의료기기 기능이라는 주장은 금지한다.

□ 다음 구현 순서

• 참가자 가이드 전
  - 합성 시나리오를 늘리되, source manifest와 라이선스 검토가 끝난 자료만 추가한다.
  - 정책의 효율·안전 오류를 별도 fixture로 재현한다.

• 참가자 가이드 후
  - 공식 API를 감싼 최소 어댑터와 `gpt-oss-20b` 1회 정상 호출 검증을 추가한다.
  - 공개 샘플과 자체 holdout을 분리한다. 비공개 평가 증례는 저장·재학습·외부 전송하지 않는다.
  - 실행 ZIP, requirements, 라이선스·출처 manifest, 재현 스크립트를 실제 환경에서 검증한다.

• 본선 진출 후
  - 20 GB VRAM 제한 안의 모델 선택은 예선 결과와 실제 환경을 본 뒤 결정한다.
  - 발표자료는 대회 성능과 MediQ 전환 가능성을 구분해 설명한다.

## 실행

```sh
cd /path/to/nova-2026
python3 scripts/validate_package.py
python3 -m unittest discover -s tests -p 'test_*.py' -v
python3 run_local_eval.py
```
